# Sprites

Carpeta para sprites de personajes, enemigos y objetos.

Estructura recomendada:
- personajes/
  - jugador/
    - idle/
    - walk/
    - attack/
  - enemigos/
- objetos/

Formatos recomendados: PNG (sin fondo), WebP, o sheets (PNG + JSON). Incluye metadatos de animación cuando sea necesario.
