# Recursos gráficos

Estructura propuesta para organizar los recursos gráficos del juego.

Carpetas:
- sprites/ (personajes, enemigos, objetos, misc)
- fondos/
- ui/
- tilesets/
- efectos/
- logos/
- fuentes/
- raw/ (archivos fuente .psd, .xcf, .ai)

Este commit crea la estructura de carpetas y archivos README básicos.

Nota: Hay un archivo existente `image.png` en `Recursos graficos/` — lo dejé en su ubicación actual para que revises y me indiques si deseas que lo mueva a alguna subcarpeta (por ejemplo `sprites/misc/`).
